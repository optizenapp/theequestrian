# Scripts Quick Reference

**Quick command reference for common maintenance tasks**

---

## Daily Operations

### Start Development Server
```bash
npm run dev
```
- Automatically generates redirects
- Runs on http://localhost:3001
- Hot reload enabled

### Build for Production
```bash
npm run build
```
- Automatically generates redirects
- Optimizes for production
- Creates static pages with ISR

---

## Weekly Maintenance (Automated)

### Product Bullet Points
```bash
# Update new products only
npm run update:bullets

# Dry run (preview)
npm run update:bullets -- --dry-run

# Force regenerate all
npm run update:bullets -- --force
```

**Automated:** Runs every Sunday 2 AM UTC via GitHub Actions

### Database Sync
```bash
# Sync products to Neon database
npm run db:sync

# Check database stats
npm run db:stats
```

**Automated:** Runs every Sunday 3 AM UTC via GitHub Actions

---

## Dynamic Features (No Maintenance Needed)

### Sitemap
- **URL:** `/sitemap.xml`
- **Status:** Automatically generated by Next.js
- **Updates:** Dynamic - always current with Shopify data
- **No script needed!**

## Quarterly Maintenance (Manual)

### Collection Content Refresh
```bash
# Dry run first (test 5 pages)
npm run master-generate-v2 -- --start=0 --max=5 --dry-run

# Process all 238 collection pages
npm run master-generate-v2 -- --start=0 --max=238

# Process specific range
npm run master-generate-v2 -- --start=50 --max=50
```

**When:** Every 3 months or when adding new categories

## As-Needed Scripts

### Product Classification
```bash
# Test on 10 products
npm run ai:classify-products -- --dry-run --limit=10

# Classify all unclassified products
npm run ai:classify-products

# Resume from previous run
npm run ai:classify-products -- --resume=exports/ai-classified-products-YYYY-MM-DD.csv
```

**When:** After bulk imports or new vendor products

### Initial Product Bullets (One-Time)
```bash
# Generate for all products (~10,000)
npm run generate:bullets

# Test first
npm run generate:bullets -- --limit=100

# Resume if interrupted
npm run generate:bullets -- --resume=exports/product-bullet-points-YYYY-MM-DD-progress.csv
```

**When:** Initial setup only (then use `update:bullets` weekly)

## Troubleshooting Quick Fixes

### CSV not updating on frontend
```bash
rm -rf .next
npm run dev
```

### Script failed midway
```bash
# Find progress file
ls exports/*-progress.csv

# Resume from last save
npm run generate:bullets -- --resume=exports/product-bullet-points-YYYY-MM-DD-progress.csv
```

### GitHub Action failed
1. Check Actions tab on GitHub
2. Review error logs
3. Verify secrets are set
4. Manually trigger workflow to retry

### Missing product bullets
```bash
# Check if product in CSV
grep "product-handle" exports/product-bullet-points-*.csv

# Update if missing
npm run update:bullets
```
