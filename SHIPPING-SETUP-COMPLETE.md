## 🎯 What Happens When You Run the Script

### Input Files
1. **Shopify product export** - Your current products
2. **vendor-shipping-rates.csv** - Vendor → shipping cost mapping
3. **tag-shipping-rates.csv** - Optional tag → shipping cost overrides

### Processing
For each product:
1. Check if product has a tag with shipping override
2. If yes → use tag shipping rate
3. If no → use vendor default shipping rate
4. Calculate: `new_price = old_price + shipping_cost`
5. Also update "Compare At Price" if present

### Output
- **Updated CSV** - Ready to import to Shopify
- **Summary report** - How many updated, skipped, etc.
- **Warnings** - Any products without shipping rates

## 🔧 Advanced: Tag-Based Overrides

### When to Use Tags

Use tag overrides when:
- Vendor sells mix of light and heavy items
- Some products need special handling (fragile, oversized)
- Specific product categories have different shipping (saddles, large rugs)

### Example Tag Strategy

**1. Create tag-shipping-rates.csv:**
```csv
tag,shipping_cost,notes
heavy,25.00,Products over 5kg
bulky,30.00,Large volume items
saddles,40.00,Saddles and heavy tack
oversized,35.00,Requires large box
fragile,18.00,Extra packaging required
```

**2. Tag products in Shopify:**
- Go to Products
- Filter by vendor or search for heavy items
- Select products
- Bulk add tags ("heavy", "saddles", etc.)

**3. Run script:**
- Products with tags use tag rates
- Products without tags use vendor rates

## 🆘 Troubleshooting Quick Fixes

### "No shipping rate for vendor: X"
**Fix:** Add vendor to `vendor-shipping-rates.csv`

### Tag override not working
**Check:**
- Tag is in `tag-shipping-rates.csv` ✓
- Product has that tag in Shopify ✓
- Tag name matches exactly ✓

### Script can't find CSV files
**Check:**
- Files are in `exports/` folder ✓
- Files named correctly ✓
- Running command from project root ✓

### Import to Shopify failed
**Check:**
- Selected "Overwrite existing products" ✓
- CSV format is correct ✓
- No missing required columns ✓
