HOW IT WORKS (THE PROCESS)
================================================================================

OVERVIEW:
────────────────────────────────────────────────────────────────────────────
1. Generate vendor list from database
2. Map each vendor to their shipping rate
3. Export all products from Shopify (CSV)
4. Run script to add shipping to prices
5. Review updated CSV
6. Import back to Shopify
7. Sync to headless database
8. Configure marketplace for free shipping
9. Test on frontend
10. Go live! 🎉

THE SCRIPT:
────────────────────────────────────────────────────────────────────────────
For each product:

1. Check if product has a tag in tag-shipping-rates.csv
   → If YES: Use tag shipping rate (e.g., "heavy" = $25.00)
   
2. If no tag match, use vendor default rate
   → e.g., "Ariat" = $12.50
   
3. Calculate: new_price = old_price + shipping_cost
   → e.g., $79.95 + $12.50 = $92.45

4. Also update "Compare At Price" if present

EXAMPLE:
────────────────────────────────────────────────────────────────────────────
BEFORE:
  Ariat Riding Shirt
  Price: $79.95
  Shipping: $12.50 (charged at checkout)
  Total: $92.45

AFTER:
  Ariat Riding Shirt
  Price: $92.45 (includes shipping)
  Shipping: FREE
  Total: $92.45

Same total, better UX! ✅

CONFIGURATION OPTIONS
================================================================================

OPTION 1: VENDOR RATES ONLY (Simple)
────────────────────────────────────────────────────────────────────────────
Use when all products from a vendor have the same shipping cost.

File: exports/vendor-shipping-rates.csv

Example:
    vendor,shipping_cost,notes
    Ariat,12.50,Clothing - lightweight
    Acavallo,15.00,Horse gear - standard
    Black Dog,15.00,Pet treats

Result:
- All Ariat products → +$12.50
- All Acavallo products → +$15.00
- All Black Dog products → +$15.00


OPTION 2: VENDOR RATES + TAG OVERRIDES (Advanced)
────────────────────────────────────────────────────────────────────────────
Use when some products within a vendor need different shipping (heavy items).

File 1: exports/vendor-shipping-rates.csv
    vendor,shipping_cost,notes
    Kentucky Horsewear,18.00,Standard items

File 2: exports/tag-shipping-rates.csv
    tag,shipping_cost,notes
    heavy,25.00,Products over 5kg
    saddles,40.00,Saddles and heavy tack

Then tag heavy products in Shopify with "heavy" or "saddles".

Result:
- Kentucky product with "saddles" tag → +$40.00 (tag overrides!)
- Kentucky product without tags → +$18.00 (vendor rate)
